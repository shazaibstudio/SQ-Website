Chatbot Test Harness

SQ Assistant — Widget Test Page

This is a plain test harness, not the real site. It exists to verify that chatbot.js drops in with a single script tag, persists conversation across page loads, and routes/qualifies/converts correctly.

How to test

  • Click the gold “Ask SQ” bubble bottom-right to open the assistant.
  • Try the guided chips first — greeting → world → services/pricing/proof.
  • Try free text too: type things like how much does a website cost, vr tour pricing, I need this urgently, or can I talk to someone.
  • Navigate to the Digital, Immersive, or Contact page using the top nav — the conversation should still be there when you reopen the widget.
  • Push the score up (ask about pricing, say it's urgent) and confirm the WhatsApp / Call handoff chips appear automatically.
Expect: guided-first Every bot message ends in tappable chips. Free typing always works too, but nothing requires it.
Expect: grounded answers Prices, services, and project examples come only from the KB object in chatbot.js — nothing invented.
Expect: quiet qualification No WhatsApp/Call push on message 1. It should escalate only after enough signal (pricing asked, urgency stated, a couple of exchanges).
Expect: persistence Reload this page or click to another test page — the widget should remember the conversation via sessionStorage, not restart it.
